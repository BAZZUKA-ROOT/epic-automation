# 🎮 Epic Games Automation

Scripts Python para automatizar a coleta de jogos gratuitos da Epic Games Store.

![Language](https://img.shields.io/badge/Stack-Python-blue) ![License](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

## O que faz

- Captura coordenadas de tela para automação do fluxo de resgate
- Automatiza os cliques para pegar jogos gratuitos semanais
- Usa `pyautogui` para controle do mouse/teclado

## Como usar

```bash
# Instalar dependência
pip install pyautogui

# 1. Mapear coordenadas da sua tela
python capturar_coordenadas_epic.pyw

# 2. Rodar a automação
python teste_automacao_epic.pyw
```

> Deixe a janela da Epic Game Store aberta antes de rodar.

## Requisitos

- Python 3.x
- pyautogui
- Epic Games Launcher instalado
